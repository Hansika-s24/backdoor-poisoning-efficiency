## Observations (one seed only)

* **Sharp threshold.** No partial backdoor at any count ≤ 100: not a single one of 200 triggered
  probes produced the sentinel. Then 191/200 at n = 200.
* **Clean behaviour unchanged.** Clean loss moves by ≤ 0.0013 and ROUGE-L by ≤ 0.009 across n;
  no false triggers.
* **Spectral signatures fire only once the backdoor exists.** AUROC 0.51–0.68 (near chance) for
  n ≤ 100; 0.932 at n = 200 (TPR 0.655 with the generous top-1.5n cut).
* **Cross-session nondeterminism.** n = 50 ROUGE-L was 0.2876 here vs 0.2862 in the timing probe
  (same seed, config and code); ASR agreed exactly at both n = 50 (0.000) and n = 200 (0.955).
  Likely nondeterministic GPU kernels; small relative to the effects above.
